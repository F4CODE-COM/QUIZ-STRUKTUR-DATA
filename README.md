DESKRIPSI :

1. Sistem Pengelolaan Nilai Mahasiswa (soal1_nilai_mahasiswa.cpp)
Program ini adalah sistem dasar untuk mencatat dan mengelola nilai mahasiswa. Pengguna bisa menambahkan data mahasiswa baru, melihat daftar keseluruhan, mengurutkan nilai mahasiswa dari yang terkecil hingga terbesar, serta mencari data spesifik berdasarkan NIM atau besaran nilainya.

2. Sistem Operasional Perpustakaan (soal2_perpustakaan.cpp)
Program ini mensimulasikan pelayanan di perpustakaan. Fitur utamanya mencakup penyimpanan dan pelacakan ID buku secara efisien, manajemen antrean mahasiswa yang ingin meminjam buku (berdasarkan urutan kedatangan), dan pencatatan riwayat pengembalian buku dari yang paling baru hingga terlama.

3. Navigasi Rute Kampus (soal3_rute_kampus.cpp)
Program ini bertindak seperti peta digital mini untuk lingkungan kampus yang terdiri dari 6 lokasi (A-F). Pengguna dapat melihat koneksi jalan antar gedung, menelusuri sebaran lokasi, dan fungsi utamanya adalah menghitung serta menampilkan rute tercepat (jarak terpendek) dari satu gedung ke gedung tujuan.

4. Penyimpanan Data Berkecepatan Tinggi (soal4_hash_table.cpp)
Program ini adalah sistem basis data mini untuk menyimpan dan mencari NIM mahasiswa yang difokuskan pada kecepatan akses. Alih-alih mencari data satu per satu dari awal, program menggunakan rumus matematika (Hash) untuk langsung menempatkan dan menemukan data di posisi yang tepat, lengkap dengan mekanisme penyelesaian bentrokan jika dua data mencoba menempati posisi yang sama.
